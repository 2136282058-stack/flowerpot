# 智能花盆控制系统

基于 **STM32F103C8T6 + FreeRTOS** 的智能花盆控制系统，集成多路传感器采集、继电器/步进电机驱动与蓝牙远程监控，实现自动浇水与远程控制。

## 功能特性

- 🌱 **多路传感器采集**：温度（DS18B20）、土壤湿度/光照（ADC）、CO2（SGP30）、红外、雨滴
- 💧 **自动浇水**：继电器控制水泵，根据土壤湿度自动 / 手动浇水
- 🎛️ **遮阳网控制**：步进电机（28BYJ-48）定时器中断 8 拍驱动
- 📱 **蓝牙远程监控**：蓝牙透传（USART1），单字符命令远程控制
- 🔄 **自动 / 手动双模式**：手动模式支持蓝牙远程控制各执行器

## 硬件平台

| 模块 | 型号 | 接口 |
|---|---|---|
| 主控 | STM32F103C8T6 | — |
| 温度传感器 | DS18B20 | 单总线 |
| 土壤湿度 / 光照 | 分压传感器 | ADC |
| CO2 传感器 | SGP30 | I2C |
| 执行器 | 5 路继电器（水泵等） | GPIO |
| 遮阳网 | 步进电机 28BYJ-48 | ULN2003 |
| 显示 | LCD / OLED | I2C |
| 通信 | 蓝牙模块 | USART1 透传 |
| RTOS | FreeRTOS | — |

## 系统架构

9 任务 + 6 队列 + 互斥锁：

- **队列广播**：传感器数据 1 生产者 → 3 消费者
- **互斥锁**：保护 LCD 共享资源，解决多任务同时写屏的冲突
- **步进电机**：定时器中断 8 拍驱动（A→AB→B→…），时序精确不丢步

## 关键设计

- **队列广播传感器数据**，避免共享全局变量带来的竞争
- **互斥锁保护 LCD**，解决显示任务与按键菜单任务同时画屏的冲突
- **步进电机定时器中断驱动**，8 拍换相精确
- **蓝牙单字符命令解析**（A~G），协议极简、易调试
- **按键菜单状态机**，实现本地交互

## 编译与烧录

1. 使用 Keil MDK5 打开 `user/stdLibPro.uvprojx`
2. 编译后烧录到 STM32F103C8T6
3. 上电后可通过蓝牙发送单字符命令远程控制
